# Archlinux instllation

First step is to ensure that you're connected to the internet. 

### Updating the system clock

The live system needs accurate time to prevent package signature verification failures and TLS certificate errors.

``` bash
$ timedatectl
```

### Partition the disks

```bash

# Check the disks

$ lsblk 

# Using cfdisk

$ cfdisk /dev/nvme0n1

```
Example layout

1. EFI partition 1 GiB - EFI system partition
2. Root partition remaining space - Linux filesystem

# Format the partitions

```Bash
$ mkfs.ext4 /dev/root_partition
$ mkfs.fat -F 32 /dev/efi_system_partition
```

# Mount the file systems

```Bash
$ mount /dev/root_partition /mnt
$ mount --mkdir /dev/efi_system_partition /mnt/boot
```

### Installation 

# Selecting the right mirrors

Packages to be installed must be downloaded from mirror servers, which are defined in `/etc/pacman.d/mirrorlist`. The higher a mirror is placed in the list, the more priority it is given when downloading a package. So choose one near your location.


# Installating the essential packages

```Bash
# You must include an editor of your choice to edit with in chroot
$ packstrap -K /mnt base linux linux-firmware efibootmgr networkmanager mkinitcpio base-devel sudo intel-ucode nvidia-open ufw neovim

```

### Configure the system

# Fstab

```Bash
$ genfstab -U /mnt >> /mnt/etc/fstab
```

# Chroot

```Bash
$ arch-chroot -S /mnt
```

# Time

```Bash
$ ln -sf /usr/share/zoneinfo/Area/Location /etc/localtime
$ hwclock --systohc
```

# Localization

```Bash
# First edit /etc/locale.gen and uncomment your choosen locale then run:
$ locale-gen

# Edit /etc/locale.conf and add: 
# LANG=en_US.UTF-8

# Edit /etc/vconsole.conf and add:
# KEYMAP=us

# Edit /etc/hostname and add:
# lora
```

# Initramfs

```Bash
$ mkinitcpio -p
```

# User creation & passwd

```Bash
# Set the root password
$ passwd 

# Create your user
$ useradd -m -G wheel -s /bin/bash username

# Set the password for your user
$ passwd username
``` 

# Enabling services


```Bash
# Enable networkmanager
$ systemctl enable NetworkManager

# Enable ufw firewall
$ sudo ufw default deny incoming
$ sudo ufw default allow outgoing
$ sudo ufw enable
$ sudo systemctl enable --now ufw.service
$ sudo ufw status verbose
```k

### Installing the bootloader


```Bash
$ bootctl --esp-path=/boot install

$ ROOT_UUID=$(findmnt -no UUID /)
$ test -n "$ROOT_UUID" || { echo "Could not detect root UUID"; exit 1; }

$ mkdir -p /boot/loader/entries

$ cat > /boot/loader/entries/arch.conf <<EOF
> title   Arch Linux
> linux   /vmlinuz-linux
> initrd  /initramfs-linux.img
> options root=UUID=$ROOT_UUID rw
> EOF

$ cat > /boot/loader/loader.conf <<'EOF'
> default arch.conf
> timeout 5
> editor no
> EOF

$ ls -l /boot/vmlinuz-linux /boot/initramfs-linux.img
$ bootctl list

$ exit 
$ umount -R /mnt
$ reboot
```
